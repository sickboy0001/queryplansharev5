# セキュリティ方針

`qps5` を安全にご利用いただくために、投稿されるデータ（Query Plan XML）の取り扱いと、ユーザー側で実施を推奨するセキュリティ対策について規定しています。

## 1. 実行プラン XML に含まれる情報について
SQL Server が生成する実行プラン（.sqlplan）には、以下のような情報が含まれる場合があります。投稿前に、これらの情報が公開されても問題ないか確認してください。

* **データベース構造**: テーブル名、インデックス名、列名、ビュー名。
* **環境情報**: サーバー名、データベース名、スキーマ名。
* **統計情報**: データの件数（推定/実際）、インデックスの分布状況。
* **ユーザー情報**: クエリを実行したログインユーザー名が含まれる場合があります。



## 2. 推奨される事前対策（マスキング）
機密性の高いシステムで取得したプランを共有する場合は、投稿前にテキストエディタ等を使用して、以下の情報を**「マスキング（ダミー名称への置換）」**することを強く推奨します。

* **サーバー名**: `Production-DB-01` → `SRV01`
* **テーブル名**: `CustomerSensitiveInfo` → `TableA`
* **その他**: 業務固有の名称が含まれる変数や定数など。

## 3. アクセス制御と公開設定の活用
情報の機密レベルに応じて、適切な公開設定を選択してください。

* **Unlisted（限定公開）**: 特定の担当者のみにレビューを依頼する場合は、一覧に表示されないこの設定を利用し、さらに**有効期限**を最短に設定してください。
* **Private（非公開）**: 第三者に一切見せたくない、個人の備忘録として利用する場合は必ずログインして「Private」を選択してください。

## 4. データの保管と削除について
* **データの削除**: 投稿者はいつでも（ゲストの場合は編集トークンを使用して）投稿を削除できます。削除されたデータは物理的にデータベースから抹消され、復元はできません。
* **管理者のアクセス**: システム管理者（Admin）は、不適切なコンテンツ（規約違反、悪意のあるスクリプト等）の監視および削除のために、投稿内容を確認する権限を有します。
* **SSL/TLS暗号化**: `qps5` との通信はすべて SSL/TLS によって暗号化されており、第三者による通信内容の傍受を防止しています。

## 5. 免責事項
`qps5` は実行プランの可視化と共有を目的としたツールであり、投稿されたデータに含まれる情報の漏洩や、それに基づいたチューニングの結果生じた損害について、当サイトは一切の責任を負いかねます。重要なデータの取り扱いは、ユーザーご自身の責任において行ってください。
